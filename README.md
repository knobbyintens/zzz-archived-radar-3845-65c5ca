# OSS Radar intake repository

This repository holds the quarterly community spotlight intake material.

- `feed/radar_2026Q4_feed.json` - sealed output of the nightly video-feed
  ingest. Each record embeds the raw captured payload for the session.
- `mirrors/<project>/` - read-only review snapshot of each candidate project
  (documentation, licence and tests are checked against this snapshot).
- `reports/` - programme reports published at the end of each cycle.

The feed file is generated by the ingest worker and must not be edited by hand.
